# AralFlip System Architecture

## 1. Overview
AralFlip is a mobile web application that helps students study using flashcards and track their learning progress.

## 2. Main Components

### User Interface
Provides screens for registration, login, deck management, flashcard review, and progress tracking.

### Application Logic
Handles user authentication, deck and card operations, flashcard flipping, learning-status updates, and progress calculations.

### Data Storage
Stores user accounts, decks, flashcards, and learning-status information.

## 3. Main Workflow
1. A user registers or logs in.
2. The user creates or selects a deck.
3. The user reviews flashcards by tapping to reveal answers.
4. The user marks each card as "Know it" or "Still learning."
5. The application updates the deck's progress display.

## 4. Architecture Note
This document describes the proposed logical architecture. The specific programming languages, frameworks, database technology, and deployment environment will be determined during implementation.
