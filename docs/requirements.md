# AralFlip Requirements

## 1. User Registration and Login
- Users can register for an account.
- Users can log in to their accounts.

## 2. Decks and Cards
- Users can create, edit, and delete decks.
- Users can create, edit, and delete flashcards.

## 3. Flashcard Review
- Users can tap a card to flip it.
- Users can mark a card as "Know it" or "Still learning."

## 4. Progress Tracking
- Each deck displays a progress bar showing how much the user already knows.

## 5. Mobile Web Application
- The app supports studying through a mobile-friendly web interface.
- A review session takes approximately 1–2 minutes.
