# AralFlip Requirements

## User Registration and Login
- Users can register for an account.
- Users can log in to their accounts.

## Decks and Cards
- Users can create, edit, and delete decks.
- Users can create, edit, and delete flashcards.

## Flashcard Review
- Users can flip cards to reveal answers.
- Users can mark cards as "Know it" or "Still learning."

## Progress Tracking
- Each deck displays a progress bar showing how much the user knows.

## Review Sessions
- A review session takes approximately 1–2 minutes.

## Platform
- AralFlip is a mobile web application.
