# Contributing to AralFlip

## Purpose

AralFlip is a mobile web app for studying with flashcards. Contributions should support the project's features and requirements.

## Development Workflow

1. Keep the `main` branch stable.
2. Create a feature branch before making changes.
3. Use clear and descriptive branch names, such as `feature/deck-management` or `docs/requirements`.
4. Make focused changes related to your assigned task.
5. Test your changes before submitting them.

## Pull Requests

1. Push your feature branch to the repository.
2. Open a pull request targeting `main`.
3. Explain what changed and why.
4. Include screenshots when changes affect the user interface.
5. Request a review from the assigned reviewer.
6. Address feedback before merging.

## Coding and Documentation

- Use clear and consistent naming.
- Keep documentation accurate and up to date.
- Avoid committing passwords, API keys, or other secrets.
- Do not modify unrelated files without coordinating with the team.

## Team Communication

Coordinate changes with the team to avoid conflicts. Ask for clarification when requirements are unclear, and communicate blockers as early as possible.
